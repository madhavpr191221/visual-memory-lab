# Project archive

This directory preserves earlier experiments and design notes. They document
how Visual Memory Lab evolved from image-based place memory into the current
video-memory system, but they are not separate products that a new user needs
to read before trying the application.

## Current source of truth

For the maintained system, start with:

- [Project README](../../README.md)
- [System design and architecture](../system_design_and_architecture.md)
- [Charades video memory](../charades_video_memory.md)
- [Guided demo](../guided_demo.md)

## Archived phase notes

`phases/` contains the chronological implementation notes. The later video
phases are retained for provenance, while the current implementation is
consolidated in `docs/charades_video_memory.md`.

## Archived supporting notes

`supporting/` contains earlier question catalogs, VLM-boundary discussions,
and research-direction notes. They are useful for background or future
experiments, but they are intentionally outside the main reading path.

The interview preparation handbook is intentionally not included in the
repository; it is personal preparation material rather than project
documentation.
