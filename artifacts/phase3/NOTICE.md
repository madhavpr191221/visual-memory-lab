# 7-Scenes-Derived Zone Artifact Notice

`office-zones.json` is a machine-assisted annotation artifact derived from the
Office scene of the Microsoft Research RGB-D Dataset 7-Scenes.

- Created: August 11, 2026
- Modification: 132 pose-spaced representative frames were described and
  verified with a VLM; verified semantic zone labels were then propagated to
  nearby observations using the dataset camera poses.
- Contents: observation identifiers, zone names, landmark descriptions,
  representative evidence metadata, assignments, counts, and provenance.
- Excluded contents: RGB images, depth images, camera-pose files, scene
  reconstructions, embeddings, model weights, and API credentials.
